# 平台与官方环境验证记录

负责人：姜晨。

本目录保存官方 SimEnv、ROS1/ROS2 适配和平台接口的可复现验证资料。每次验证必须有
`README.md`、`summary.json`、测试记录 CSV；截图、视频和原始 rosbag 放共享盘或压缩归档，并在
README 中写明索引。不得以“桥接进程存在”替代控制、传感器或任务闭环的真实证据。

`official_simenv_ros1_ros2/20260714_ros1_clean_direct_acceptance/` 已完成隔离 ROS1 原生控制和
RGB-D/内参/雷达/里程计实测：直行超过 1 m、转向和零速度保持均有原始里程计证据。它不覆盖 ROS2
到 ROS1 控制、ROS2 `/hw/*` 传感器或业务闭环；这些项仍待安装 ROS2 运行时后的逐段实测。记录必须
分别标明每一项是否真正通过；未通过项不得以订阅数或日志替代。
