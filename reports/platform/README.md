# 平台与官方环境验证记录

负责人：姜晨。

本目录保存官方 SimEnv、ROS1/ROS2 适配和平台接口的可复现验证资料。每次验证必须有
`README.md`、`summary.json`、测试记录 CSV；截图、视频和原始 rosbag 放共享盘或压缩归档，并在
README 中写明索引。不得以“桥接进程存在”替代控制、传感器或任务闭环的真实证据。

本目录保留多个阶段的验收记录，不能由单个“通过”目录推断当前共享平台已可用。每次记录必须分别标明 ROS1
直连控制、ROS2 到 ROS1 控制、RGB-D/内参、里程计、业务闭环和进程清理是否真正通过；未通过项不得以订阅数或日志替代。
当前操作边界与最新接入方式以 [`docs/guidebook/官方SimEnv平台环境使用手册.md`](../../docs/guidebook/官方SimEnv平台环境使用手册.md) 为准。
