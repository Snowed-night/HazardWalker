# 比赛材料目录

本目录用于存放 HazardWalker 项目参加挑战杯比赛所需的各类材料，按组别和用途组织。

## 目录结构说明

| 文件夹 | 负责人 | 内容说明 |
|---|---|---|
| `platform/` | 王文丰 | 平台组材料：官方 SimEnv 接入、接口文档、GUI/headless 方案、录制方案 |
| `nav/` | 徐嘉骏 | 导航组材料：SLAM、探索策略、路径优化和返航约束说明 |
| `perception/` | 黄亚锌 | 感知组材料：红球检测、动态识别、主动视角、多帧确认和三维定位材料 |
| `testing/` | 宋艺多 | 测试组材料：测试指标定义、测试记录汇总、实验结果统计 |
| `decision/` | 黄鸣波 | 决策组材料：状态机设计、决策逻辑、结果汇总机制 |
| `common/` | 潘冠淇 | 通用材料：比赛要求清单、获奖项目调研、技术报告大纲、PPT 素材 |

## 文件命名规范

- 文档类：`<日期>_<主题>.md`，例如 `20260715_testing_metrics.md`
- 表格类：`<日期>_<主题>_summary.csv` / `.json`
- 图片类：`<主题>_<描述>.png`，例如 `perception_accuracy_trend.png`

## 提交要求

- 各组在 2026 年 7 月 18 日前完成本组材料整理
- 材料需包含：技术方案说明、实验结果、关键参数、问题与改进方向
- 所有材料需经过离线测试验证，确保可复现
- 提交前需运行 `python scripts/run_offline_tests.py` 确认无语法错误
