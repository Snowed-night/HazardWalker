# 测试组材料目录

本目录存放比赛要求清单、获奖项目调研、技术报告大纲、PPT 素材等。

## 目录结构

```
common/
├── README.md # 本说明文件
├── 20260716_final_submission_checklist.md # 最终提交材料清单
├── 20260716_detailed_technical_solution_template.docx # 详细技术方案模板
├── 20260716_self_testing_report_template.docx # 自测试报告模板
├── 20260716_wangwen_yiliao_ppt.pdf # 望问医聊项目答辩PPT（原始版）
├── 20260716_wangwen_yiliao_ppt_revision.pdf # 望问医聊项目答辩PPT（修改版）
├── 慧眼逐明PPT.pdf # 慧眼逐明项目参考PPT
├── 基于四足机器人的危险源自主搜索与识别技术.pdf # 比赛方案原文（含评分标准、提交要求）
└── 报名.pdf # 2026年度揭榜挂帅擂台赛报名表
```

## 文件说明

| 文件 | 说明 |
|---|---|
| `final_submission_checklist.md` | 最终需提交的5项材料清单（技术方案报告、答辩PPT、核心代码、自测试报告、演示视频），含截止时间与线上线下提交方式 |
| `detailed_technical_solution_template.docx` | 揭榜项目实施方案完整模板，含12个一级章节（必要性、研发内容、技术指标、创新点、技术路线、可行性分析、经费预算等） |
| `self_testing_report_template.docx` | 自测试报告模板，含测试目的、测试环境、测试方法、评价指标、实验结果、榜单指标符合性验证、测试结论等章节 |
| `wangwen_yiliao_ppt.pdf` | 望问医聊项目原始答辩PPT，共37页，含项目概述、创始人故事、核心技术（Prophet框架）、三大创新点、竞品分析、商业模式、财务预测等 |
| `wangwen_yiliao_ppt_revision.pdf` | 望问医聊项目答辩PPT修改版，调整了页面结构和内容侧重，增加了揭榜挂帅相关标注 |
| `慧眼逐明PPT.pdf` | 第八届互联网+国赛项目“慧眼逐明”参考PPT，共29页，含创业初心、市场痛点、核心技术（三维重建+多模态融合）、商业模式等，可作为PPT制作参考 |
| `基于四足机器人的危险源自主搜索与识别技术.pdf` | 比赛方案原文（DG-202602），含题目介绍、参赛对象、答题要求、作品考核过程（测试验证+答辩）、评选标准（创新性25分+技术实现50分+应用价值25分）、提交方式、奖项设置（擂主10万元）等完整信息 |
| `报名.pdf` | 2026年度中国青年科技创新“揭榜挂帅”擂台赛学生赛道报名表，含申报者信息（姜晨等10人）、合作者情况、指导老师信息、学校认定盖章等 |
