# 第 23 轮：闭环复查约束与返航脱困实测

## 结论

本轮在官方 `auto.sh` 随机复杂楼宇、固定 `SEED=2026071802` 下运行，使用
公开 RGB、深度、相机内参、雷达、IMU、合法 SLAM 和控制接口；运行期未读取
Gazebo 位姿、危险物模型名或生成场景元数据。

导航闭环完成：机器人自主入楼、扩展单层 Cartographer 地图、覆盖主走廊和
`y>0` 侧向房间区域，随后自动返航到距起点 `0.24 m`，状态为
`RETURNING → FINISHED`。第 22 轮定位出的返航问题得到实测修复：

- 有效 A* 路径不再每 3 秒无条件重算。
- 返航初段静止后只触发 1 次有界脱困转向。
- 脱困转向实测航向变化 `0.810 rad`，随后恢复平移。
- 返航东西向大方向序列只有 `east → west`，即 1 次必要的绕障反向；之后持续
  向起点收敛，没有复现第 22 轮的多次路径振荡。

但本轮不是完整感知成功：4945 帧中没有红球候选、没有三维目标，也没有主动复查
事件。`mission_completed=true` 只说明探索节点完成了返航状态机，不代表已经完成
比赛的危险源识别任务。正式结果仅含空的 `detected_danger_sources`，因此本轮不得
宣称获得官方有效识别成绩。
