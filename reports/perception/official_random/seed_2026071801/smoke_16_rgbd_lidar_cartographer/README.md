# Smoke 16：RGB-D 中带扫描 + 水平雷达融合

## 目的

将对齐深度图转换为第二路 `LaserScan`，补充官方水平雷达在复杂楼宇中垂直视场不足的问题，同时保持运行期只读取官方公开 RGB-D、雷达、IMU 和控制输入。

## 结果

- `/hw/depth_scan` 为 320 条射线，视场约 -29.87°～29.95°，量程 0.4～8.0 m。
- `ros2 topic hz` 的短墙钟样本约 1.28 Hz；Cartographer 的仿真时间日志显示稳定约 5.6～8.7 Hz。
- Cartographer 同时接收 `scan_1=/hw/scan`、`scan_2=/hw/depth_scan`、IMU 和合法里程计，并持续插入 submap。
- 保存了初始、旋转后、前进后三阶段 PGM/YAML/PNG 地图与前后 RGB 截图。

## 限制

地图覆盖面积明显扩大，但仍存在射线扇形和稀疏障碍边界，说明传感器标定/地面过滤与运动轨迹仍需优化。本轮只证明双扫描融合链路可运行，不宣称全楼高质量 SLAM。
