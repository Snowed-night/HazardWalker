# 官方随机场景 SEED=2026071801 联调轨迹

本目录保留失败、中间修复和当前可用结果，用于展示算法优化路径。它不是五类正式感知套件，也不能直接当作官方得分证明；正式五类证据仍应使用同一固定 SEED、同一代码版本和统一测试表格重跑。

## 结论

- `smoke_01`～`smoke_03`：早期感知、ICP 和 SLAM 接线验证，均未形成任务闭环。
- `smoke_04`～`smoke_08`：定位时钟、水平雷达、机器人自体回波和 frontier 失败原因。保留用于解释为何旧 `slam_toolbox` 链路“进程在、地图不可用”。
- `smoke_10`：官方控制器、公开传感器和独占会话基础链路通过，但没有发现危险源，不能记感知成功。
- `smoke_11`～`smoke_12`：合法控制先验定位的误差收敛过程；仍不是可靠 SLAM。
- `smoke_13`：Cartographer 首次 scan+IMU 建图；修复仿真时间后可用，但纯扫描平移约束不足。
- `smoke_14`：加入仅使用公开输入的合法里程计。原地旋转估计与事后真值诊断接近。
- `smoke_15`：识别官方 A1 线速度死区，0.20 m/s 基本不动、0.35 m/s 可稳定推进；frontier 实际发出控制并使机器人移动，但该轮仍有外部停止产生的旧清理异常，不能称为完整自主探索。
- `smoke_16`：融合 RGB-D 中带深度扫描和水平雷达，两个扫描源均被 Cartographer 接收；地图扩大，但障碍边界仍稀疏，暂不宣称高质量全楼建图。
- `smoke_17`：仓库正式 `official_simenv_business.launch.py` 入口验收。独立 ROS2 域中节点、双扫描、合法里程计、IMU、唯一 `/map` 发布者及地图落盘均通过。

当前可靠口径是“官方公开输入下已能控制、定位并生成占据栅格，正式业务入口可运行”；尚未完成多层未知楼宇全覆盖、回环精度和红球任务闭环，不应写成 SLAM/自主探索全部完成。
