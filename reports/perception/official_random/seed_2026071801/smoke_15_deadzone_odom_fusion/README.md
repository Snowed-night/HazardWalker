# Smoke 15：A1 控制死区、合法里程计与 Frontier

## 目的

确认“导航发了速度但机器人不走”究竟是控制链失效还是官方 A1 的速度死区，并验证 Cartographer 是否能融合公开雷达、IMU 与合法控制先验。

## 结果

- 0.20 m/s 低速段：事后 Gazebo 真值诊断位移约 0.0058 m，合法估计约 0.0032 m，说明该速度基本落在死区内。
- 0.35 m/s 有效段：事后真值位移约 1.0065 m，合法估计约 1.0078 m；该校准段的位移幅值误差约 0.13%。
- 有效段真值偏航变化约 7.27°，估计约 6.77°。
- 修正 Cartographer 概率自由栅格阈值、frontier 小簇回退、恢复时序和 A* 堆实现后，节点选到 `(2.99, 28.74)` 前沿，路径 570 个栅格，并实际发布 0.30 m/s、0.45 rad/s 控制。
- 机器人随后由事后真值位置约 `(-0.49, -4.81)` 移动至 `(3.90, -5.80)`；由于中间多轮参数实验没有连续同起点轨迹，本数值只证明真实移动，不计算整段定位误差。

## 限制

该轮 frontier 进程由测试脚本外部停止，旧版本留下 `ExternalShutdownException` 清理回溯；后续代码已改为幂等关闭并通过离线测试，但本目录保留原日志以展示问题路径。本轮不等同于完整楼宇自主探索成功。
