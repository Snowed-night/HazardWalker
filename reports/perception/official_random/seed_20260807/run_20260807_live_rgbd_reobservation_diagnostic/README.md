# SEED 20260807 实时 RGB-D 主动复查诊断

本目录记录官方 ROS1 SimEnv 随机复杂楼宇中的一次真实在线感知诊断。机器人由
Frontier 导航进入楼内；感知节点只读取公开 RGB、深度、相机内参和合法激光—IMU
SLAM 位姿。运行期未读取危险源真值、场景内部目标坐标或 Gazebo 真值里程计。

## 目的

- 验证运动期间候选不会直接累计为已确认危险源；
- 验证 `/hw/cmd_vel` 已归零且相机位姿连续稳定后才累计独立视角；
- 验证部分/边缘候选能够触发转向和侧移复查；
- 验证红球经多视角 RGB-D 球面几何确认后输出三维世界坐标；
- 暴露长时记录体积和未完成复查 episode 等后续问题。

## 结果

- 逐帧记录：2782 帧；稳定视角帧 572 帧；停止命令帧 695 帧；最长连续稳定 140 帧。
- 主动复查 episode：7 次，其中 1 次以 `confirmed` 闭环，6 次在本轮结束时未闭环。
- 已确认红球：1 个；确认坐标约为 `(0.2035, 15.5657, 0.3274)`，坐标系为 `world`。
- 确认时取得 3 个独立稳定视角，红球表观直径中位数约 0.303 m，归一化深度曲率
  中位数约 0.147，无平面/各向异性反证；先通过强 RGB-D 几何路径确认，后续视角
  将水平视线跨度扩展到 131.1°，满足常规多视角路径。
- 同轮还出现第 2 个球面候选并完成三维定位，但复查未闭环，因此没有写成确认危险源。

## 证据说明

- `images/raw/` 与 `images/annotated/` 保存相同时间戳的代表性原图和标注图，依次覆盖
  边缘候选、首个稳定球面视角、首次确认、第二目标球面候选和后续大视差确认。
- `depth/` 保存上述代表帧对应的米制深度数组。
- `summary.json`、测试组 CSV/JSON、`run_manifest.json`、轨迹和 Cartographer 地图均来自
  同一运行实例。

## 适用范围

该轮在未提交代码上以 `diagnostic_official_random_scene` 运行，并在完成关键感知验证后
人工安全结束；`mission_completed=false`，也没有生成最终 `detected_danger.json`。因此它
只作为算法优化路径和真实在线闭环证据，不能作为完整任务、返航成功或官方成绩证据。
未提供赛后真值，本目录不计算识别率、虚警率和定位误差。
