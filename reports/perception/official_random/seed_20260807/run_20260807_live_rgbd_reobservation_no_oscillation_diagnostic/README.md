## 目的

验证稳定相机门控、候选目标主动复查、多视角球体确认，以及新加入的复查动作防振荡规则。重点检查机器人在看到贴边或部分可见红球后，是否会从转向动作稳定过渡到同侧横移，而不是在横移和转向间逐帧反复切换。

## 结果

- 共处理 5949 帧，其中 864 帧存在候选且均完成三维候选定位。
- 记录 4 次主动复查过程，其中 `candidate-3` 在 `1.3 s` 内由部分可见候选确认成 1 个危险源。
- `candidate-3` 的动作序列为 `turn_left -> move_left`，未出现修复前的 `move_left -> turn_left -> move_left` 逐帧振荡。
- 最长稳定观察连续 218 帧；平均处理耗时 `2.662 ms`，P95 `5.155 ms`，输出频率约 `10.005 Hz`。
- 本轮未完成整场任务。导航返程阶段当前位置距起点约 `32.16 m`，历史最佳约 `9.63 m`，持续出现返程漂移并在 3600 秒诊断上限结束。该问题属于导航闭环，不能据此否定已经形成的感知主动复查证据。

## 结论

本轮证明防振荡修改对成功确认的复查过程有效，并在真实复杂官方随机楼宇中形成了完整的候选、动作、确认和定位记录。由于缺少真值且整场任务未完成，只能作为阶段诊断成果；正式得分仍需在导航返程修复后按官方随机模式重新验收。
