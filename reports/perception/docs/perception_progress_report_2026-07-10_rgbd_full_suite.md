# 感知组进度记录：RGB-D 完整回归与误报抑制

日期：2026-07-10

本记录延续 [2026-07-05 感知进度报告](perception_progress_report_2026-07-05.md) 的“后续修改计划”，针对低可见球漏检、圆柱误判、密集目标分离、主动重观察和三维定位链路做了代码实现与官方平台实测，而非只补充静态截图。

## 已实现改进

1. 修复 `red_ball_detector.py` 中 Hough 粘连球分裂分支的损坏逻辑，并保持距离变换、分水岭和 Hough 圆的组合路径。
2. 增加局部/暗光候选分支：严格 HSV+形状筛选不通过时，仍可在较低亮度阈值下输出低置信度的 `requires_reobservation` 候选；候选不进入三维确认轨迹。
3. 增加 RGB-D 深度形状证据：对 bbox 的中心椭圆和外环分别取深度中位数；球面应表现为外环更远，近似平面则标记 `flat`。只有明确 `flat` 才禁止确认，深度不足保持 `unknown` 并交给重观察，避免误杀遮挡球。
4. 主动视角策略加入 `flat` 分支：圆形但深度平坦的红色物体优先建议横移复查，不再仅凭单视角圆度确认。
5. 新增官方平台自动采集脚本：每例独立创建受控模型、启动隔离的感知节点、保存原生 RGB 标注图和 JSON 快照，并使用 Gazebo PoseInfo 的实体 ID 清理模型，避免用例串扰。

## 当前结论

“低可见直接漏掉”和“圆柱单帧被确认”已在当前可运行链路上得到针对性处理：前者转成可执行的重观察任务，后者被深度几何禁止进入 confirmed。HSV/OpenCV 仍是可解释基线，不应称为 SOTA；下一阶段 SOTA 化工作的关键是接入稳定四足真实运动，获得第二视角后验证多视角一致性、深度尺寸一致性与 confirmed 轨迹的端到端指标。

## 后续验收条件

- 平台提供稳定 A1 控制后，记录至少左/右两个真实视角，要求 `distinct_view_count >= 2` 才允许 confirmed。
- 对圆柱、平板和球体补充多距离、多材质、不同光照曲线，统计 confirmed 级 FP/FN，而非只统计 2D 候选。
- 将受控模型位置与输出世界坐标逐例匹配，记录定位误差均值、P95 和失配原因。
- 继续评估实例分割或训练型检测后端，但保留当前 `DetectionBackend` 与完整回归结构，避免模型替换破坏可解释性和复现性。
