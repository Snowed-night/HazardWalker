# official_simenv_20260710_rgbd_localization

官方 SimEnv 原生 RGB-D 世界坐标定位矩阵。使用半径 `0.15 m` 的受控球，在当前相机实际 FOV 内选取 6 个不同距离/横向位置；不读取官方危险源真值。

## 结果

| 用例 | 受控位置 (m) | 3D 误差 (m) |
|---|---|---:|
| 01 | (0.00, -0.20, 0.30) | 0.0112 |
| 02 | (-0.25, -0.20, 0.30) | 0.0183 |
| 03 | (0.25, -0.20, 0.30) | 0.0256 |
| 04 | (0.00, 0.00, 0.30) | 0.0118 |
| 05 | (-0.30, 0.00, 0.30) | 0.0206 |
| 06 | (0.30, 0.00, 0.30) | 0.0118 |

6/6 通过；平均误差约 `0.0166 m`，最大误差 `0.0256 m`。每例均具备 RGB、对齐深度、CameraInfo、world TF 与严格候选。见 `images/localization_collage.png`、`snapshots/`、`cases.csv/json` 和测试组镜像。

该结论仅覆盖当前官方 headless 平台与标准半径球；超出当前相机 FOV 的位置不能被写作“定位失败”，应先由主动视角策略把目标带入可见区域。
