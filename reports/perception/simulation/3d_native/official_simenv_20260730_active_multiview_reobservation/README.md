# 官方 SimEnv：部分可见红球主动多视角复查

> 证据等级：内部可控专项回归，不是官方随机场景整场成绩，也不证明导航组 SLAM、Frontier 或 Nav 已完成。

## 环境与目的

- 环境：官方 ROS1 Noetic + Gazebo Classic + Unitree A1，业务侧 ROS2 Jazzy。
- 传感器：仅使用公开 RGB、深度、相机内参、激光/IMU 和运行期 TF；检测与运动策略不读取真值。
- 真实运行：2026-07-23 21:18:07 至 21:45:33 UTC，共 1646.478 s。
- 隔离容器：`hazardwalker_perception_isolated_stage_b_20260723`，`ROS_DOMAIN_ID=77`。
- SEED：`2026073001`；代码：`local-feature-perception-bd7492c-uncommitted`。
- 目的：验证红球只露出约 15%、25%、35% 时先输出黄色候选框，再由感知建议驱动 A1 实际移动，最终取得多视角球面证据、唯一确认和三维定位。

## 方法

1. 在官方生成楼宇内，按当前相机前方 1.2 m 临时放置一个半径 0.15 m 红球和黑色遮挡板；每场结束删除夹具。
2. 左、右两侧各测试 15%、25%、35% 三种可见比例，共 6 场。首帧必须是未确认的部分候选。
3. 感知只发布重观察语义；测试编排器经 `/hw/cmd_vel` 执行转向、横移或靠近，并用运行期 `tf://map/base` 记录实际位移。
4. 确认门槛为至少 3 个离散视角、至少 2 个球面深度正证据、视线跨度至少 25°；同一目标只允许保留 1 条轨迹。
5. 真值只在快照落盘后计算定位误差，不进入检测、跟踪、动作选择或确认逻辑。

- 通过：6/6；候选召回：100%。
- 确认级虚警：0；确认级重复目标：0。
- 平均定位误差：0.4736 m；最大定位误差：0.7766 m，满足本专项不超过 1 m 的门槛。
- 每场均由部分候选开始，经真实运动后形成唯一确认轨迹；右侧 25% 场验证了跨定位漂移仍保持同一候选/轨迹。

## 结论与边界

本轮证明当前感知链能够完成“部分可见候选 → 主动换视角 → 多视角球面确认 → 三维定位 → 去重”的可控专项闭环。它没有完成未知楼宇自主搜索，也没有使用导航组正式探索栈；官方随机场景鲁棒性仍需在导航组提供可复核的运动建图与覆盖证据后单独验收。

完整逐帧图像、深度图和快照在 `images/`、`snapshots/`，结构化指标在 `summary.json`、`cases.csv/json`，测试组记录在本目录及 `reports/perception/test_records/` 的同名目录。
