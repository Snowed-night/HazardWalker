# official_simenv_20260710_rgbd_multi_count

官方 SimEnv 原生 RGB-D 多红球数量递进和粘连球分离实验。

## 覆盖与结果

- 均匀分离红球：1、2、3、4、5、6、8、10 个，共 8 例；每例严格候选数与受控目标数完全一致。
- 相切双球：2 个严格候选，验证 Hough/分水岭路径没有把粘连目标合并。
- 9/9 通过，展示图见 `images/multi_count_collage.png`。

此前单个大球可能被 Hough 同时输出整球圆和内嵌小圆，导致重复计数。本轮将嵌套/高重叠框作为同一目标去重后，在真实 Gazebo 渲染的 1–10 递进场景中没有再出现多计。

逐例候选数量、节点快照、CSV/JSON 和测试组镜像均已保留；原始帧和运行日志不提交 Git。
