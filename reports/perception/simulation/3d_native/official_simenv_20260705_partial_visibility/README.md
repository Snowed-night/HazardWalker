# official_simenv_20260705_partial_visibility

官方 SimEnv 原生 Gazebo 3D 前景遮挡实验。

## 重要修正

旧版遮挡图中遮挡片贴近或穿过球体，不能作为有效 3D 遮挡证据。本目录已替换为修正版：灰色遮挡板明确位于相机和红球之间。

空间位置：

- camera_y: 27.868
- foreground_plate_y: 30.188
- ball_y: 30.968

因此遮挡板在相机和球体之间，而不是穿过球体。

## 内容

- `images/`: 原生 Gazebo 3D 截图检测标注图。
- `images/collage.png`: 遮挡比例总览。
- `cases.csv/json`: 每个案例的目标可见比例、实际红色像素比例、检测结果。
- `summary.json`: 汇总结果。
- `raw_frames.zip`: 原始 PPM 归档，不展开提交。

## 结果

- 基准图：1 张，无前景遮挡。
- 前景遮挡图：20 张，左/右遮挡，目标可见比例 5% 到 85%。
- 检出：10/20
- 漏检：10
- 修正版中实际红色像素比例约 0.31 以下全部漏检，约 0.43 以上开始稳定检出。
- 最小检出实际红色像素比例：0.434
