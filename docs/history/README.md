# 历史资料

本目录用于保留可追溯的旧方案、排障记录和阶段环境快照。它们不代表当前可用流程，尤其不得将历史 Gazebo Harmonic、旧双栈目录或旧主力机地址用于官方 SimEnv。

- `legacy_harmonic/`：早期本地 Gazebo Harmonic / 旧 ROS 双栈方案。
- `infrastructure/`：早期主力机环境建设记录。
- `project_early/`：早期最小 demo、fake 平台与阶段开发路线。

需要恢复历史信息时，先与当前 [官方 SimEnv 平台环境使用手册](../guidebook/官方SimEnv平台环境使用手册.md) 和实际代码核验。
