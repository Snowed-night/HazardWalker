## 1. 你能用什么

主力机已搭建完成，各组拥有**独立 Linux 账号**和**独立代码目录**，可同时进行开发而互不干扰。

当前已具备：

- ROS 2 Jazzy、Gazebo Harmonic、Nav2、SLAM Toolbox、Gazebo 桥接等系统依赖
- 各组 `~/HazardWalker` 仓库（以 `dev` 为统一基线，按任务再切功能分支）
- 公共 PyTorch CUDA 环境（感知组 YOLO 预研用）
- 共享大文件目录（模型、数据集、rosbag 等）
- oh-my-zsh 终端环境（主题 `ys`，已配置 ROS）

最小 demo 验收标准（离线测试 + 构建 + fake platform 闭环）已在集成组与测试组账号验证通过。

## 3. 目录与环境

登录后你的个人目录结构：

```text
~/HazardWalker/              # 你的独立 Git 仓库
~/HazardWalker/ros2_ws/      # 你的独立 colcon 工作空间（各自 build，不共享）
~/venvs/pytorch              # 公共 PyTorch CUDA（软链，YOLO 实验用）
~/datasets  -> /srv/hazardwalker/datasets
~/models    -> /srv/hazardwalker/models
~/rosbags   -> /srv/hazardwalker/rosbags
~/videos    -> /srv/hazardwalker/videos
```

### 3.1 仓库分支

| 账号 | 分支 |
|---|---|
| 全部组员 | 默认同步 `dev`，按任务创建或切换功能分支 |

拉取更新：

```bash
cd ~/HazardWalker
git fetch origin
git pull
```

### 3.2 自动加载的环境

登录 zsh 后自动生效：

1. ROS 2 Jazzy（系统级）
2. 本组 `ROS_DOMAIN_ID`（文档组无此项）
3. 若已构建：你的工作空间 `~/HazardWalker/ros2_ws/install/setup.zsh`

### 3.3 终端自定义（oh-my-zsh）

已按队长机 `hxbl` 样板配置：

- 主题：`ys`
- 插件：`git` `sudo` `extract` `z` `docker` `web-search`
- 补全高亮：`zsh-autosuggestions`、`zsh-syntax-highlighting`

可自行修改（不会被管理员覆盖）：

- `~/.zshrc` 中 `# --- USER CUSTOM ---` 段落
- `~/.oh-my-zsh/custom/local.zsh`

## 4. 日常开发流程

### 4.1 首次登录检查

```bash
whoami
echo $ROS_DOMAIN_ID     # 应显示本组编号（文档组为空）
ros2 --help
cd ~/HazardWalker
./scripts/setup_env.sh
```

### 4.2 标准验证（每次开发前建议执行）

```bash
cd ~/HazardWalker

# 1. 离线算法测试（不需要 ROS）
python3 scripts/run_offline_tests.py
# 预期：10 passed, 0 failed

# 2. 构建 ROS 2 工作空间
./scripts/build.sh
# 预期：6 packages finished

# 3. 启动最小 demo
./scripts/run_minimal_demo.sh
# 等待完成或 Ctrl+C 结束

# 4. 检查结果
ls reports/run_results
python3 scripts/evaluate_result.py reports/run_results/<timestamp>_result.json
# 预期：status=FINISHED, return_success=true
```

### 4.3 PyTorch / GPU 实验（感知组 YOLO 预研）

```bash
source ~/venvs/pytorch/bin/activate
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
deactivate    # 跑 ROS 前务必退出
```

**重要：** 不要在 PyTorch venv 或 conda 里执行 `colcon build` 或 `run_minimal_demo`。

## 5. 必须遵守的规则

| 规则 | 说明 |
|---|---|
| 用本组账号 | 不要共用他人账号 |
| 用本组 `ROS_DOMAIN_ID` | 多组同时跑节点时，否则 `/hw/*` 话题会串 |

| 大文件放共享目录 | 模型/rosbag/视频放 `~/models` 等，**不进 Git** |
| GPU 使用先报备 | 集成组优先；用完说明已释放 |
| Docker 需申请 | 默认仅管理员账号可用 |
| 不用 conda 跑 ROS | conda 仅用于离线实验（当前全员无 conda） |

### 磁盘注意

- `/srv/hazardwalker`（1.8T）：**共享大文件放这里**

## 7. 常见问题

**Q：git push 失败？**

A：当前仓库为 HTTPS clone，push 需配置 GitHub 个人访问令牌或 SSH key，联系集成组协助。

**Q：`ros2` 找不到？**

A：确认使用 `zsh` 登录（默认已是），或手动 `source /opt/ros/jazzy/setup.zsh`。

**Q：`./scripts/build.sh` 报错？**

A：先 `source /opt/ros/jazzy/setup.bash` 再构建；仍失败请联系集成组。

**Q：想换终端主题？**

A：编辑 `~/.zshrc` 中 `ZSH_THEME="ys"` 改为其他主题名即可。

**Q：环境问题找谁？**

A：测试与集成组（环境管理员账号 `hazard_admin`）。
