# HazardWalker 6月14日至7月4日各组任务计划

## 1. 本阶段总体目标

本阶段覆盖期末考试周，期间不集中开会、每组需要围绕“下次开会能展示仿真平台效果”推进一个可验证成果。

到 7 月 4 日前，全队目标如下：

1. 平台组确认 Gazebo 仿真平台是否能被各组账号使用，并给出统一使用方式。
2. 感知组在 Gazebo 截图或仿真图像中稳定输出红球检测结果，包括完整红球、局部红球和多红球场景。
3. 导航组至少能在仿真或最小 demo 中说明 `/hw/odom -> /hw/cmd_vel -> /hw/nav/state` 的运行链路。
4. 集成测试组建立统一测试记录目录和表格，能记录每次仿真、离线测试、截图脚本和结果文件。
