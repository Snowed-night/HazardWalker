    -> 订阅 /hw/odom

## 5. 当前并行开发方向

最小闭环只负责验证接口和启动流程。各组从初期就应并行推进正式比赛需要的能力：

- 平台组：Gazebo 最小场景和官方平台适配边界。
- 导航组：Frontier、SLAM Toolbox、Nav2 goal 接入。
- 感知组：从 2D bbox 推进到相机 + 点云 + TF 三维定位。
- 决策组：把状态转发升级为探索、识别、重观察、返航、失败处理。
- 测试组：建立探索耗时、识别率、虚警率、返航成功率的记录方式。

固定航点、HSV 和 fake platform 是起步验证手段，不是最终系统。
