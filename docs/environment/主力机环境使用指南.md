## 2. SSH 登录方式

Tailscale 私网入口：

```bash
ssh <你的账号>@100.102.91.31
```

公网跳板入口：

```bash
ssh -p 6002 <你的账号>@47.98.141.33
```

说明：

- `47.98.141.33` 是阿里云公网跳板机，不是最终开发主机。
- `6002` 端口方案本质是反向 SSH 隧道。
- Tailscale 是整机级服务，不按 Linux 用户隔离；登录后的权限隔离依赖 Linux 账号。
- 全员配置 SSH 公钥后，集成组会逐步关闭 SSH 密码登录。

推荐在本机 `~/.ssh/config` 或 Windows `C:\Users\<用户名>\.ssh\config` 写入快捷配置：

```sshconfig
Host hxbl-ts
    HostName 100.102.91.31
    User hazard_按本组修改

Host hxbl
    HostName 47.98.141.33
    Port 6002
    User hazard_按本组修改

Host hxbl-rdp-tunnel
    HostName 47.98.141.33
    Port 6002
    User hazard_按本组修改
    LocalForward 13389 127.0.0.1:3389
```

## 4. 每个账号的开发环境

各组只在自己的 home 目录开发：

```text

/home/hazard_nav/HazardWalker
/home/hazard_perception/HazardWalker
/home/hazard_decision/HazardWalker
```

常用流程：

```bash
cd ~/HazardWalker
git fetch origin
git pull

./scripts/run_minimal_demo.sh
```

检查结果：

```bash

```

当前最小 demo 验收标准是：离线测试通过、ROS 工作空间能构建、fake platform 闭环能写出结果 JSON。

## 5. Python、conda 与 GPU

普通离线算法和 ROS 构建优先使用系统 Python：

```bash
python3 --version
python3 scripts/run_offline_tests.py
```

PyTorch / GPU 实验使用公共 PyTorch CUDA 环境：

```bash
source ~/venvs/pytorch/bin/activate
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
deactivate
```

规则：

- 不要在 PyTorch venv 或 conda 环境里执行 `colcon build` 或 `run_minimal_demo`。
- 普通离线测试不占用 GPU。
- 需要占用 GPU 前先通知集成组；用完说明已释放。
- 禁止长期挂后台训练、渲染或仿真不报备。

## 7. 常见问题

**Q：`ros2` 找不到？**

A：确认使用默认 zsh 登录，或手动执行 `source /opt/ros/jazzy/setup.zsh`。

**Q：`./scripts/build.sh` 报错？**

A：先运行 `./scripts/setup_env.sh`，确认 ROS、colcon 和 rosdep 可用；仍失败联系集成组。

**Q：git push 失败？**

A：主力机仓库可能是 HTTPS clone，需要配置 GitHub SSH key 或 Personal Access Token。优先联系集成组统一处理。

**Q：需要图形界面运行 RViz/Gazebo GUI？**

A：看 [远程桌面使用指南](远程桌面使用指南.md)。
