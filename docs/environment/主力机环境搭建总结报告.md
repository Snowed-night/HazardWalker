### 2.4 SSH 公钥与 GitHub（建议尽快完成）

#### 主力机免密登录

1. 本机若无密钥，生成一对 SSH 密钥：

```bash
ssh-keygen -t ed25519 -C "你的昵称或邮箱"
# 一路回车即可（或自行设置 passphrase）
```

1. 查看并复制**公钥**（`.pub` 文件，一行）：

```bash
cat ~/.ssh/id_ed25519.pub
```

1. 提交公钥（二选一）：
  - **发给集成组**：将公钥全文、组别与 `hazard_`* 账号名发给集成组，由管理员写入。
  - **自行上传**：用 SFTP / Remote-SSH 将 `id_ed25519.pub` 传到自家目录（如 `~/id_ed25519.pub`）。若自行追加到 `~/.ssh/authorized_keys`，按集成组文档操作。**无论哪种方式，都必须告知集成组**（谁、哪个账号、何时上传），便于登记；勿在未通报的情况下静默改密钥。
2. 生效后即可用 `ssh hazard_xxx@...` **免密登录**，无需再输入临时密码。

#### GitHub push 配置

当前主力机仓库为 **HTTPS clone**，直接 `git push` 会失败。任选其一（推荐 SSH）：


| 方式                        | 做法                                                                                                                      |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **GitHub SSH key（推荐）**    | 将同一把或新生成的公钥添加到 GitHub → Settings → SSH and GPG keys；在本机或主力机把 `origin` 改为 `git@github.com:Snowed-night/HazardWalker.git` |
| **Personal Access Token** | 在 GitHub 创建 PAT，HTTPS push 时用 token 作为密码                                                                                |


不确定如何操作时，联系集成组协助。配置完成前，可在主力机拉取代码、本地改完后由集成组协助推送，或自行在已配置凭据的本机 clone 开发。

### 2.5 本机 SSH 配置模板（推荐）

将下面内容追加到本机 SSH 配置文件，**把 `User` 改成你的 `hazard_*` 账号**（示例为平台组）。配置公钥后，可取消注释 `IdentityFile` 行。

| 系统 | 配置文件路径 |
| --- | --- |
| macOS / Linux | `~/.ssh/config` |
| Windows | `C:\Users\<你的用户名>\.ssh\config`（无则新建） |

**合并模板（SSH + 公网 RDP 隧道）：**

```sshconfig
# Tailscale — 日常 SSH
Host hxbl-ts
    HostName 100.102.91.31
    User hazard_platform
    # IdentityFile ~/.ssh/id_ed25519

# 公网跳板 — 日常 SSH
Host hxbl
    HostName 47.98.141.33
    Port 6002
    User hazard_platform
    # IdentityFile ~/.ssh/id_ed25519

# 公网跳板 — 远程桌面前先开此连接（见 2.6 / 远程桌面使用指南.md）
Host hxbl-rdp-tunnel
    HostName 47.98.141.33
    Port 6002
    User hazard_platform
    LocalForward 13389 127.0.0.1:3389
    # IdentityFile ~/.ssh/id_ed25519
```

**用法：**

```bash
ssh hxbl-ts              # Tailscale SSH
ssh hxbl                 # 公网 SSH
ssh hxbl-rdp-tunnel      # 公网 RDP 隧道（保持不关）→ RDP 连 127.0.0.1:13389
```

说明：

- 模板写在**你自己电脑**上，不是主力机；每人 `User` 不同，勿共用账号。
- 全员改用 SSH 公钥后，日常 `ssh hxbl` / `hxbl-ts` 免密；`hxbl-rdp-tunnel` 同样走公钥，**RDP 登录密码不变**（见《远程桌面使用指南.md》§2.3）。
- 远程桌面 Tailscale 路径 RDP 直连 `100.102.91.31:3389`，无需 `LocalForward`。

### 2.6 远程桌面（RDP）

用于 **RViz、Gazebo GUI** 等图形界面。完整步骤、**账号与密码**见队内文档 **[远程桌面使用指南.md](远程桌面使用指南.md)**（含 Windows / macOS / **Linux**、Tailscale 与公网跳板两种路径）。

要点：两层登录（RDP 网关 `hazard_rdp` → GDM 本组 `hazard_*`）；公网路径须在本机建立 SSH 隧道后再连 `127.0.0.1:13389`。**禁用 SSH 密码登录不影响 RDP 密码**（仍用文档中的网关密码与 Linux 密码；SSH 改公钥，见该文档 §2.3）。**不同 `hazard_*` 可同时 RDP；同一账号不可两路独立桌面并行**（见该文档 §1.1）。

## 4. 日常开发流程

### 4.1 首次登录检查

```bash
whoami
echo $ROS_DOMAIN_ID     # 应显示本组编号（文档组为空）
ros2 --help
cd ~/HazardWalker
./scripts/setup_env.sh
```

### 4.2 标准验证（每次开发前建议执行）

```bash
cd ~/HazardWalker

# 1. 离线算法测试（不需要 ROS）
python3 scripts/run_offline_tests.py
# 预期：10 passed, 0 failed

# 2. 构建 ROS 2 工作空间
./scripts/build.sh
# 预期：6 packages finished

# 3. 启动最小 demo
./scripts/run_minimal_demo.sh
# 等待完成或 Ctrl+C 结束

# 4. 检查结果
ls reports/run_results
python3 scripts/evaluate_result.py reports/run_results/<timestamp>_result.json
# 预期：status=FINISHED, return_success=true
```

### 4.3 PyTorch / GPU 实验（感知组 YOLO 预研）

```bash
source ~/venvs/pytorch/bin/activate
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
deactivate    # 跑 ROS 前务必退出
```

**重要：** 不要在 PyTorch venv 或 conda 里执行 `colcon build` 或 `run_minimal_demo`。

## 7. 常见问题

**Q：git push 失败？**  
A：见 **2.4 节** GitHub 配置；需添加 GitHub SSH key 或 PAT。仍有问题联系集成组。

**Q：如何免密登录主力机？**  
A：见 **2.4 节**，将 SSH 公钥发给集成组添加；配置 **2.5 节**模板后可用 `ssh hxbl` / `ssh hxbl-ts` 快捷连接。

**Q：`ros2` 找不到？**  
A：确认使用 `zsh` 登录（默认已是），或手动 `source /opt/ros/jazzy/setup.zsh`。

**Q：`./scripts/build.sh` 报错？**  
A：先 `source /opt/ros/jazzy/setup.bash` 再构建；仍失败请联系集成组。

**Q：想换终端主题？**  
A：编辑 `~/.zshrc` 中 `ZSH_THEME="ys"` 改为其他主题名即可。

**Q：环境问题找谁？**  
A：测试与集成组。

**Q：远程桌面连不上？**  
A：见 **[远程桌面使用指南.md](远程桌面使用指南.md)**（含账号密码与 Windows / Mac 步骤）。
