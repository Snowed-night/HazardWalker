# HazardWalker 主力机远程桌面使用指南

更新时间：2026-06-07  
适用对象：**全队成员**  
目标机器：`hxbl`（Ubuntu 24.04 + GNOME Remote Login）

> **含账号与密码，仅限队内传阅，勿转发到公开群聊或仓库外网。**

---

## 1. 适用场景

- RViz、Gazebo GUI 等**图形界面**开发
- 与 **SSH 终端开发并存**；无 GUI 需求时仍优先 SSH
- 多组可**同时**连接，各用**不同**的 Linux 账号，桌面环境隔离

### 1.1 多人 / 多机能否同时登录？

| 情况 | 能否同时登录 | 说明 |
| --- | --- | --- |
| **不同** `hazard_*`（如 `hazard_platform` 与 `hazard_nav`） | **可以** | 各组独立桌面、home、`ROS_DOMAIN_ID` 互不干扰 |
| **同一** `hazard_*` 从两台电脑同时 RDP | **不可以** | 不能两个独立桌面并行 |
| 全队共用 RDP 网关 `hazard_rdp` | **可以多人同时用** | 网关只是「进门」；进 GDM 后须用**各自** Linux 账号 |

同一 Linux 账号在 Linux/GNOME 下通常**只允许一个图形会话**。同一 `hazard_*` 若从第二台设备再连，常见结果是：**顶掉**已有 RDP，或**接到同一会话**，不会出现两个独立远程桌面。

因此：**一人一号、一机一路 RDP**；换电脑时先断开旧连接再连新的。禁止两人共用同一 `hazard_*` 登桌面。

## 2. 账号与密码（两层登录）

连接时会先后出现 **两次** 登录，不要混用密码。

### 2.1 第一层：RDP 网关（全队共用）


| 项   | 值                      |
| --- | ---------------------- |
| 用户名 | `hazard_rdp`           |
| 密码  | `HazardWalkerRdp2026!` |


说明：`hazard_rdp` **不是** Linux 系统账号，仅用于进入 GDM 登录界面。

### 2.2 第二层：GDM Linux 登录（各组独立）

在图形登录界面使用**本组**账号，密码与 SSH 相同：


| 组别  | Linux 账号             | 密码                 | ROS_DOMAIN_ID |
| --- | -------------------- | ------------------ | ------------- |
| 集成与测试组 | `hazard_test` | `HazardWalker2026` | 20 |
| 平台组 | `hazard_platform` | `HazardWalker2026` | 11 |
| 导航组 | `hazard_nav` | `HazardWalker2026` | 12 |
| 感知组 | `hazard_perception` | `HazardWalker2026` | 13 |
| 决策组 | `hazard_decision` | `HazardWalker2026` | 14 |
| 文档组 | `hazard_docs` | `HazardWalker2026` | — |


**禁止**共用他人 Linux 账号。

### 2.3 与「禁用 SSH 密码登录」的关系

集成组在全员配置 SSH 公钥后，会**关闭 SSH 密码登录**（仅允许公钥连 SSH）。这与远程桌面密码**无关**：


| 登录方式                        | 禁用 SSH 密码后                 | 密码是否变化                    |
| --------------------------- | -------------------------- | ------------------------- |
| **SSH 终端**                  | 须用 **SSH 公钥**，不能再靠密码 `ssh` | —                         |
| **RDP 第一层**（`hazard_rdp`）   | **不受影响**                   | 仍为 `HazardWalkerRdp2026!` |
| **RDP 第二层**（GDM `hazard_`*） | **不受影响**                   | 暂时仍为 `HazardWalker2026`   |


说明：

- 「禁用 SSH 密码」只改 **sshd** 的连入方式，**不会**自动修改 Linux 账号密码，也**不会**修改 RDP 网关密码。
- 远程桌面 GDM 仍用 Linux 账号 + 密码验证，与 SSH 是否允许密码是**两套机制**。
- **公网 RDP 隧道**：关闭 SSH 密码后，建立 `ssh -L` 时须用 **公钥**（或已配置的免密登录），但连上 RDP 后，网关与 GDM **仍用本文档 §2.1、§2.2 的密码**。

## 4. Windows 连接步骤

### 4.1 Tailscale 路径（推荐）

1. 安装 [Tailscale for Windows](https://tailscale.com/download/windows) 并登录
2. `Win + R` → 输入 `mstsc` → 回车
3. 计算机：`100.102.91.31:3389`
4. 连接 → 第一层：`hazard_rdp` / `HazardWalkerRdp2026!`
5. GDM 界面 → 本组 `hazard_`* / `HazardWalker2026`

### 4.2 公网跳板路径（SSH 隧道）

**第一步**：在本机打开 **PowerShell** 或 **CMD**（不要先 SSH 进 hxbl），执行（把账号改成你的）：

```powershell
ssh -p 6002 hazard_platform@47.98.141.33 -L 13389:127.0.0.1:3389
```

输入本组 Linux 密码 `HazardWalker2026`，**保持此窗口不关**。

**第二步**：`Win + R` → `mstsc` → 计算机：`127.0.0.1:13389`

**第三步**：登录同 4.1（先 `hazard_rdp`，再 GDM 本组账号）。

> 若提示找不到 `ssh`：设置 → 应用 → 可选功能 → 添加 **OpenSSH 客户端**。

## 5. macOS 连接步骤

推荐客户端：**Microsoft Remote Desktop（Windows App）** 或 **Remmina snap**。

### 5.1 Tailscale 路径

1. 本机登录 Tailscale
2. 新建 RDP 连接：`100.102.91.31:3389`
3. 第一层：`hazard_rdp` / `HazardWalkerRdp2026!`
4. GDM：本组 `hazard_`* / `HazardWalker2026`

### 5.2 公网跳板路径

**在本机 Mac 终端**（不要 inside 已 SSH 到 hxbl 的会话里）：

```bash
ssh -p 6002 hazard_platform@47.98.141.33 -L 13389:127.0.0.1:3389
```

RDP 连接 `**127.0.0.1:13389**`，登录步骤同上。

### 5.3 macOS 报错 0x207 时

Microsoft Remote Desktop 可能出现 `Error code: 0x207`，与密码过期无关。处理：

1. 在客户端 **Add PC** 并填好地址与 `hazard_rdp` 凭据
2. **Export** 为 `.rdp` 文件
3. 文本编辑，将 `use redirection server name:i:0` 改为 `use redirection server name:i:1`
4. **双击修改后的 .rdp 文件** 连接

## 6. Linux 连接步骤

推荐客户端：**Remmina**（桌面 GUI）或 **xfreerdp**（命令行）。不推荐发行版自带的旧版 FreeRDP 若无法完成 H.264 协商，可优先用 Remmina。

### 6.1 安装客户端

**Debian / Ubuntu：**

```bash
sudo apt update
sudo apt install remmina remmina-plugin-rdp
# 可选命令行：sudo apt install freerdp3-x11   # 或 freerdp2-x11，视发行版而定
```

**Fedora：**

```bash
sudo dnf install remmina remmina-plugins-rdp
```

**Arch：**

```bash
sudo pacman -S remmina freerdp
```

### 6.2 Tailscale 路径（推荐）

1. 安装并登录 [Tailscale](https://tailscale.com/download/linux)
2. 打开 **Remmina** → 新建连接
   - 协议：**RDP**
   - 服务器：`100.102.91.31:3389`
   - 用户名：`hazard_rdp`
   - 密码：`HazardWalkerRdp2026!`
   - 安全：接受自签证书 / 忽略证书验证（视客户端选项而定）
3. 连接 → 出现 GDM 后，用本组 `hazard_*` / `HazardWalker2026` 登录

**命令行示例（xfreerdp）：**

```bash
xfreerdp /v:100.102.91.31:3389 /u:hazard_rdp /p:'HazardWalkerRdp2026!' /cert:ignore +clipboard
```

GDM 登录在图形界面中完成。

### 6.3 公网跳板路径（SSH 隧道）

**第一步**：在**本机 Linux 终端**（不要先 SSH 进 hxbl）开隧道（账号改成你的）：

```bash
ssh -p 6002 hazard_platform@47.98.141.33 -L 13389:127.0.0.1:3389
```

保持该终端不关。禁用 SSH 密码后，须已配置公钥免密（见 §2.3）。

**第二步**：Remmina 新建连接

- 服务器：`127.0.0.1:13389`
- 用户名 / 密码：同 §6.2（先 `hazard_rdp`，再 GDM 本组账号）

**命令行示例：**

```bash
xfreerdp /v:127.0.0.1:13389 /u:hazard_rdp /p:'HazardWalkerRdp2026!' /cert:ignore +clipboard
```

### 6.4 与 §7 SSH 模板配合

配置 `~/.ssh/config` 中的 `hxbl-rdp-tunnel` 后：

```bash
ssh hxbl-rdp-tunnel    # 保持不关
remmina                # 连接 127.0.0.1:13389
```

## 7. SSH 配置模板（可选，公网路径）

写入本机 `~/.ssh/config`，将 `User` 改为本组 `hazard_`*：

```sshconfig
Host hxbl-rdp-tunnel
    HostName 47.98.141.33
    Port 6002
    User hazard_需要自行修改
    LocalForward 13389 127.0.0.1:3389

Host hxbl-ts
    HostName 100.102.91.31
    User hazard_platform
```

用法：`ssh hxbl-rdp-tunnel` → RDP 连 `127.0.0.1:13389`；Tailscale 下 RDP 仍直连 `100.102.91.31:3389`。

| 规则                | 说明                                |
| ----------------- | --------------------------------- |
| 用本组 Linux 账号登 GDM | 不要共用他人账号                          |

## 10. 常见问题

**Q：连 `127.0.0.1:13389` 失败？**  
A：确认隧道在**你自己的电脑**上运行且未关闭。Windows：`Test-NetConnection 127.0.0.1 -Port 13389`；Linux：`ss -tlnp | grep 13389` 或 `nc -zv 127.0.0.1 13389`。

**Q：第一层密码不对？**  
A：必须用 `hazard_rdp` / `HazardWalkerRdp2026!`，不是 Linux 密码。

**Q：GDM 密码不对？**  
A：用本组 `hazard_`* / `HazardWalker2026`。

**Q：黑屏或闪退？**  
A：联系集成组；并说明是 Tailscale 还是公网隧道、Windows / macOS / Linux。

**Q：同一个 `hazard_*` 能在两台电脑上同时远程桌面吗？**  
A：**不能**两个独立桌面并行。第二路连接会顶掉或并入已有会话。不同组用不同 `hazard_*` 可同时在线。见 **§1.1**。

**Q：禁用 SSH 密码登录后，远程桌面密码会变吗？**  
A：**不会。** SSH 只能公钥登录；RDP 网关仍为 `hazard_rdp` / `HazardWalkerRdp2026!`，GDM 仍为本组 `hazard_`* / `HazardWalker2026`。公网隧道改用 SSH 公钥建立，RDP 层密码不变。见 **§2.3**。

**Q：环境问题找谁？**  
A：测试与集成组。
