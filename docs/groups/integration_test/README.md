# 集成测试组文档

集成测试组负责跨组接口验收、离线回归、正式联调记录和失败边界归档。

## 当前工作边界

- 测试规范和 CSV/JSON 字段以 [测试记录规范](../../guidebook/测试记录规范.md) 为准；不再维护本组或平台组的重复模板。
- 运行入口为 `python scripts/run_offline_tests.py`。最近一次在当前工作区的离线回归为 **302 passed, 0 failed**；该结果仅覆盖离线契约，不代表官方仿真闭环。
- 平台、导航、感知和决策的真实运行证据必须落到各自 `reports/<group>/` 目录，并链接到测试记录。

## 本组提交材料

- [历史主力机环境运维手册](主力机环境运维手册_20260606.md)：仅供追溯，主力机连接和运维以 `docs/guidebook/待确认/` 的管理员复验结论为准。
- 文档组维护的阶段测试指标、失败汇总和测试数据位于 [`../docs/competition_materials/testing/`](../docs/competition_materials/testing/)，均为带日期的阶段材料，不替代当前测试结论。

新增联调记录必须包含：参与模块版本、输入输出话题、启动顺序、独占控制约束、原始证据路径、结果、失败边界和复跑步骤。
