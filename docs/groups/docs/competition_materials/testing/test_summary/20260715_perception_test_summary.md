## 5. 算法改进记录

| 改进项 | 说明 |
|---|---|
| 粘连分离 | 先检查凹缺陷深度，再调用 Hough/分水岭 |
| 同连通域拆分 | 拆出的圆标记 `from_merged_split`，需后续独立轮廓确认 |
| 多视角确认 | 默认要求三个稳定停靠视角，运动期间冻结跟踪证据 |
| 轨迹联合检查 | 三维位置一致性、表观直径变异、深度曲率变异 |
| 侧视要求 | 最终确认要求目标相对相机水平视线跨度至少 25° |
