### 2.3 关键结论

1. **先转后走**：|heading_error| > 0.25rad 时 linear_x=0，确保先对准方向
2. **到达切换**：距离 <= 0.5m 时 goal_index 自动 +1，不需要外部干预
3. **接近减速**：linear_x = min(0.35, distance)，防止冲过目标
4. **RETURNING 判定**：goal_index == len(waypoints)-1 时为 RETURNING，表示最后一个航点（返航）
5. **FINISHED 条件**：completed=True 或 waypoints 为空 或 goal_index 超出范围
6. **角速度饱和**：angular_z 被 clamp 到 [-0.8, +0.8] rad/s
