# HazardWalker 测试指标定义文档

## 1. 概述

本文档定义 HazardWalker 项目各模块的测试指标体系，用于评估系统性能、跟踪开发进度、支撑比赛材料撰写。

测试指标分为五个维度：平台组、导航组、感知组、决策组、集成测试组。

## 2. 平台组测试指标

### 2.1 指标定义

| 指标名称 | 定义 | 计算公式 | 单位 | 验收标准 |
|---|---|---|---|---|
| 接口可用性 | 测试的话题/接口是否能正常收发消息 | 通过接口数 / 总接口数 | % | ≥ 90% |
| 话题发布频率 | 各话题的实际发布频率 | 消息数 / 时间 | Hz | 接近标称值 ±20% |
| 话题延迟 | 消息从产生到被订阅的平均延迟 | 接收时间 - 发送时间 | ms | ≤ 100ms |
| 控制系统接口稳定性 | 控制系统接口稳定运行时间占比 | 稳定运行时间 / 总运行时间 | % | ≥ 95% |
| 控制响应时间 | 控制指令从发出到生效的时间 | 机器人开始响应时间 - 指令发送时间 | ms | ≤ 50ms |
| 传感器数据完整率 | 有效传感器数据帧占总帧数的比例 | 有效帧 / 总帧数 | % | ≥ 98% |
| 仿真同步率 | 仿真时间与实际时间的同步程度 | 仿真时间 / 实际时间 | % | 95% ~ 105% |
| GUI/headless可用性 | GUI 或 headless 模式是否正常工作 | 正常工作次数 / 总尝试次数 | % | ≥ 90% |

### 2.2 接口清单

| 接口 | 类型 | 标称频率 | 坐标系 | 发布者 | 使用组 |
|---|---|---|---|---|---|
| `/camera/image_raw` | `sensor_msgs/Image` | 30Hz | front_camera | SimEnv | 感知 |
| `/camera/camera_info` | `sensor_msgs/CameraInfo` | 30Hz | front_camera | SimEnv | 感知 |
| `/real_sense/depth/points` | `sensor_msgs/PointCloud2` | 10Hz | real_sense | SimEnv | 感知/导航 |
| `/Odometry_gazebo` | `nav_msgs/Odometry` | 待测 | world/base | SimEnv | 导航/测试 |
| `/cmd_vel` | `geometry_msgs/Twist` | 控制输入 | base | 导航 | 平台 |

## 3. 导航组测试指标

### 3.1 指标定义

| 指标名称 | 定义 | 计算公式 | 单位 | 验收标准 |
|---|---|---|---|---|
| 探索时间 | 完成探索任务所用总时间 | 任务结束时间 - 任务开始时间 | s | 根据场景评估 |
| 探索覆盖率 | 探索区域占目标区域的比例 | 已探索区域面积 / 总目标区域面积 | % | ≥ 80% |
| 目标点数 | 本次测试的航点/探索目标点总数量 | 成功到达的目标点数 | 个 | 根据场景评估 |
| 卡死次数 | 检测到的卡死/停滞事件次数 | 停滞时间 > 阈值的事件数 | 次 | ≤ 3次 |
| 返航结果 | 返航是否成功 | 成功 / 失败 / 未触发 | - | 成功 |
| 航点到达率 | 成功到达航点数占计划航点数的比例 | 成功到达数 / 计划数 | % | ≥ 95% |
| 平均航点间隔 | 相邻航点之间的平均距离 | 总路径长度 / 航点数 | m | 根据场景评估 |
| 卡顿时长 | 每次卡顿的平均持续时间 | 总卡顿时间 / 卡顿次数 | s | ≤ 5s |
| 返航成功率 | 成功返航次数占总返航尝试次数的比例 | 成功次数 / 总尝试次数 | % | ≥ 90% |
| 返航耗时 | 从触发返航到到达目标点的用时 | 到达时间 - 触发时间 | s | 根据场景评估 |

## 4. 感知组测试指标

### 4.1 指标定义

| 指标名称 | 定义 | 计算公式 | 单位 | 验收标准 |
|---|---|---|---|---|
| 识别率（召回率） | 正确识别的红球数占真值总数的比例 | TP / (TP + FN) | % | ≥ 90% |
| 漏检率 | 未检测到的真实红球数占真值总数的比例 | FN / (TP + FN) | % | ≤ 10% |
| 虚警率（误检率） | 误识别的非红球数占检测总数的比例 | FP / (TP + FP) | % | ≤ 5% |
| 定位误差 | 定位坐标与实际坐标的欧氏距离 | sqrt((x-x')² + (y-y')² + (z-z')²) | m | ≤ 0.15m |
| 检测帧率 | 每秒处理的图像帧数 | 处理帧数 / 时间 | FPS | ≥ 10FPS |
| 多帧确认率 | 通过多帧验证的检测比例 | 多帧确认数 / 总检测数 | % | ≥ 95% |
| 平均检测耗时 | 单帧图像检测平均处理时间 | 总处理时间 / 帧数 | ms | ≤ 100ms |
| 识别数量 | 成功识别的目标总数 | 正确检测数 | 个 | 根据场景评估 |
| 虚警数量 | 误识别的虚假目标数 | false positive 数 | 个 | ≤ 2个 |

### 4.2 术语解释

| 术语 | 解释 |
|---|---|
| TP (True Positive) | 正确检测到的红球数量 |
| FP (False Positive) | 误检为红球的非红球数量 |
| FN (False Negative) | 未检测到的红球数量 |
| IoU (Intersection over Union) | 检测框与真值框的交并比，用于评估检测精度 |

## 5. 决策组测试指标

### 5.1 指标定义

| 指标名称 | 定义 | 计算公式 | 单位 | 验收标准 |
|---|---|---|---|---|
| 状态转移次数 | 状态机状态切换的总次数 | 状态切换事件数 | 次 | 根据任务复杂度评估 |
| 任务完成率 | 成功完成任务次数占总任务次数的比例 | 成功次数 / 总次数 | % | ≥ 80% |
| 决策延迟 | 从接收到决策执行的时间间隔 | 执行时间 - 接收时间 | ms | ≤ 100ms |
| 正确决策率 | 正确决策次数占总决策次数的比例 | 正确次数 / 总次数 | % | ≥ 90% |
| 异常恢复率 | 从异常状态成功恢复的次数占异常发生次数的比例 | 成功恢复次数 / 异常次数 | % | ≥ 80% |
| 结果汇总准确率 | 结果汇总与实际情况的符合度 | 正确汇总数 / 总汇总数 | % | ≥ 95% |
| 任务执行时间 | 任务从开始到结束的总时间 | 结束时间 - 开始时间 | s | 根据场景评估 |
| 重观察触发次数 | 触发重新观察的次数 | reobservation 请求数 | 次 | 根据场景评估 |
| NBV 决策次数 | Next Best View 决策执行次数 | NBV 请求数 | 次 | 根据场景评估 |

### 5.2 状态机状态定义

| 状态 | 说明 |
|---|---|
| INITIALIZING | 初始化中 |
| EXPLORING | 探索中 |
| DETECTING | 检测中 |
| CONFIRMING | 确认目标中 |
| REOBSERVING | 重观察中 |
| REPLANNING | 重新规划中 |
| RETURNING | 返航中 |
| FINISHED | 任务完成 |
| FAILED | 任务失败 |
| TIMEOUT | 任务超时 |

## 6. 集成测试组测试指标

### 6.1 指标定义

| 指标名称 | 定义 | 计算公式 | 单位 | 验收标准 |
|---|---|---|---|---|
| 完整任务耗时 | 从任务开始到输出结果的总时间 | 结束时间 - 开始时间 | s | 根据场景评估 |
| 危险源输出数量 | 结果文件中确认的危险源数量 | confirmed hazards 数 | 个 | 根据场景评估 |
| 系统崩溃次数 | 测试过程中系统崩溃/异常退出次数 | 崩溃事件数 | 次 | ≤ 1次 |
| 结果文件完整性 | 结果文件是否包含所有必需字段 | 完整字段数 / 必需字段数 | % | 100% |
| 离线测试通过率 | 离线测试通过数占总测试数的比例 | 通过数 / 总数 | % | 100% |
| 端到端成功率 | 完整任务从开始到成功输出结果的比例 | 成功次数 / 总次数 | % | ≥ 70% |

### 6.2 结果文件必需字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `mission_id` | string | 任务唯一标识 |
| `status` | string | 任务状态 |
| `duration_sec` | float | 任务耗时 |
| `return_success` | bool | 是否成功返航 |
| `hazard_count` | int | 检测到的危险源总数 |
| `confirmed_hazard_count` | int | 确认的危险源数量 |
| `hazards` | array | 危险源列表（含坐标） |
| `timestamp` | string | 结果生成时间 |

## 7. 测试记录规范

### 7.1 文件命名

```
testing_record_<组名>.json
testing_record_<组名>.csv
```

组名：`platform` / `nav` / `perception` / `decision` / `integration_test`

### 7.2 目录结构

```
reports/<组名>/test_records/<YYYYMMDD_HHMMSS>/
    ├─ testing_record_<组名>.json
    └─ testing_record_<组名>.csv
```

### 7.3 基本信息字段

| 字段 | 说明 |
|---|---|
| 日期 | 测试执行日期，格式 `YYYY-MM-DD` |
| 成员 | 测试执行人姓名 |
| 分组 | 所属组别 |
| 分支 | Git 分支名 |
| 命令 | 执行的完整命令 |
| 测试环境 | 测试运行环境 |
| 是否通过 | 通过 / 失败 / 部分通过 |
| 失败信息 | 失败时的错误信息 |
| 耗时 | 测试总执行时间 |
| 备注 | 其他说明 |

## 8. 指标统计方法

### 8.1 统计维度

- **时间维度**：按日期统计各指标变化趋势
- **场景维度**：按不同测试场景统计指标表现
- **模块维度**：按各功能模块统计指标分布

### 8.2 数据汇总

所有测试数据汇总至 `reports/<组名>/test_records/` 目录，定期整理为汇总表格，用于：
- 技术报告数据支撑
- PPT 图表素材
- 答辩数据展示
