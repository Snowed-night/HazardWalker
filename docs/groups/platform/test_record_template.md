# 测试记录表模板


## 一、基本测试记录


### 说明


本部分记录测试的基本信息，适用于所有测试场景。


| 字段 | 说明 |
| :--- | :--- |
| **日期**  | 测试执行日期，格式为 YYYY-MM-DD |
| **成员**  | 测试执行人员姓名 |
| **分组**  | 测试所属组别（平台组/感知组/导航组/决策组/集成测试组） |
| **分支**  | 测试所在的 Git 分支名称 |
| **命令**  | 执行的测试命令或脚本路径 |
| **测试环境**  | 测试环境描述（本机离线/主力机SSH/主力机RDP/实机） |
| **是否通过**  | 填写「通过」「失败」或「部分通过」 |
| **失败信息**  | 测试失败时填写错误信息或关键堆栈 |
| **耗时**  | 测试总执行时间，单位秒或分钟 |
| **备注**  | 其他需要说明的事项 |

## 三、使用说明


1. **记录基本测试信息** ：在「一、基本测试记录」中填写测试的通用信息，所有字段必填（失败信息仅失败时填）
2. **选择对应分组** ：根据测试内容选择「分组」字段，共 5 组：平台组、感知组、导航组、决策组、集成测试组
3. **填写专项参数** ：在对应分组的专项测试表中填写相关指标，有数据填数据，无数据填"未测试"或说明原因
4. **保存为 JSON + CSV** ：测试记录同时保存 JSON 和 CSV 两种格式，JSON 方便程序读取，CSV 方便表格查看
5. **统一存放目录** ：按 `reports/<组名>/test_records/<YYYYMMDD_HHMMSS>/` 目录存放
6. **失败必须记录** ：失败的测试更要记录，写清楚错误信息、复现步骤和环境信息
