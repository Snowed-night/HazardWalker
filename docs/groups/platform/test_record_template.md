# 测试记录表模板


## 一、基本测试记录


### 说明


本部分记录测试的基本信息，适用于所有测试场景。


| 字段 | 说明 |
| :--- | :--- |
| **日期**  | 测试执行日期，格式为 YYYY-MM-DD |
| **成员**  | 测试执行人员姓名或 ID |
| **分组**  | 测试所属组别（感知组/导航组/决策组/平台组） |
| **分支**  | 测试所在的 Git 分支名称 |
| **命令**  | 执行的测试命令或脚本路径 |
| **测试环境**  | 测试环境描述（仿真/实机/测试机） |
| **是否通过**  | 填写「通过」或「失败」 |
| **失败信息**  | 测试失败时填写错误信息或堆栈跟踪 |
| **备注**  | 其他需要说明的事项 |

### 2.1 感知组测试参数


#### 职责说明


感知组负责红色球体检测、三维定位、虚警抑制和危险源去重。


#### 感知组专项指标


| 指标名称 | 说明 | 单位 |
| :--- | :--- | :--- |
| **检测准确率**  | 正确检测数 / (正确检测数 + 漏检数) | % |
| **虚警率**  | 虚警数量 / 总检测数量 | % |
| **识别数量**  | 成功识别的目标总数 | 个 |
| **虚警数量**  | 误识别的虚假目标数 | 个 |
| **漏检数量**  | 未检测到的真实目标数 | 个 |
| **定位误差**  | 定位坐标与实际坐标的欧氏距离 | m |
| **平均检测耗时**  | 单帧图像检测平均处理时间 | ms |
| **检测帧率**  | 每秒处理的图像帧数 | FPS |
| **多帧确认率**  | 通过多帧验证的检测比例 | % |

## 三、使用说明


1. **记录基本测试信息** ：在「一、基本测试记录」中填写测试的通用信息
2. **选择对应分组** ：根据测试内容选择「分组」字段
3. **填写专项参数** ：在对应分组的专项测试表中填写相关指标
4. **关联记录** ：通过日期和成员字段关联基本记录与专项参数
