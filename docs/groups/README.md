# 各组文档索引

本目录按小组归档任务说明、接口约定、阶段交付和实验记录模板。

| 目录 | 负责范围 |
|---|---|
| `platform/` | Gazebo/官方平台适配、传感器话题、TF、仿真场景 |
| `nav/` | SLAM、Nav2、Frontier 探索、返航策略 |
| `perception/` | 红球检测、三维定位、多帧确认、低虚警 |
| `decision/` | FSM、任务状态、重观察、超时和失败处理 |
| `integration_test/` | 主力机验收、离线测试、系统评估、实验记录 |
| `docs/` | 赛事材料、系统框图、答辩文档、会议纪要整理 |

每组文档优先回答四个问题：

1. 本组模块输入是什么。
2. 本组模块输出是什么。
3. 当前占位实现在哪里。
4. 下一阶段可验收交付是什么。
