# HazardWalker 项目背景介绍

## 1. 项目基本信息

- 项目名称：HazardWalker
- 赛题编号：DG-202602
- 赛题名称：基于四足机器人的危险源自主搜索与识别技术
- 项目目标：在未知多层楼栋仿真环境中，让四足机器人自主探索、识别红色球体危险源、完成三维定位、输出结果并自主返航。

## 2. 任务定义

- 机器人从固定起点出发，坐标原点以任务起点为准。
- 主要识别目标是红色球体危险源。
- 系统需要输出危险源相对起点的三维坐标和任务结果。
- 项目当前以仿真环境和离线算法为主，先固定接口，再逐步替换实现。

## 3. 系统结构

```text
仿真平台 / 官方平台
        |
hazardwalker_platform
        |
HazardWalker 内部接口
        |
nav / perception / decision
        |
hazardwalker_bringup
        |
结果输出 / 指标统计
```

### 3.1 模块职责

- `hazardwalker_platform`：平台适配，统一仿真和官方平台输入输出。
- `hazardwalker_nav`：固定航点、导航、返航和卡死恢复。
- `hazardwalker_perception`：红球检测、点云辅助定位、多帧确认和去重。
- `hazardwalker_decision`：任务状态机、目标切换、返航约束和结果汇总。
- `hazardwalker_bringup`：一键启动和系统集成。
- `hazardwalker_msgs`：自定义消息定义。

## 4. 核心接口

### 4.1 传感器与控制

- `/hw/camera/image_raw`
- `/hw/camera/camera_info`
- `/hw/lidar/points`
- `/hw/odom`
- `/hw/cmd_vel`
- `/tf`
- `/tf_static`

### 4.2 导航与任务

- `/hw/nav/state`
- `/hw/nav/goal`
- `/hw/perception/hazard_detections`
- `/hw/mission/state`
- `/hw/mission/result`

## 5. 已确认工程原则

- `hazardwalker_platform` 是唯一平台适配入口。
- 算法模块只面向 `/hw/*` 内部接口。
- 第一阶段先用固定航点和 HSV，先跑通最小闭环。
- 官方平台发布后优先做平台适配，不直接重写算法。
- 主力机用于集成，个人环境用于模块开发。
