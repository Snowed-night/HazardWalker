# 主力机环境搭建

本文档用于在主力机上初始化 HazardWalker 开发环境。

目标环境：

```text
Ubuntu 24.04
ROS 2 Jazzy
Gazebo Harmonic
NVIDIA RTX A6000 驱动正常
```

## 1. 先确认硬件和系统

在主力机终端运行：

```bash
lsb_release -a
uname -a
lscpu
free -h
lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINT,MODEL
lspci | grep -i nvidia
```

如果 `lspci` 能看到 RTX A6000，但 `nvidia-smi` 不能运行，说明显卡驱动还没装好或没有加载。

## 2. 检查 NVIDIA 驱动

先运行：

```bash
nvidia-smi
```

如果提示命令不存在或无法连接驱动，运行：

```bash
sudo ubuntu-drivers devices
```

按 Ubuntu 推荐方式安装驱动：

```bash
sudo ubuntu-drivers install
sudo reboot
```

重启后再次检查：

```bash
nvidia-smi
```

如果学校网络慢，先不要急着装 CUDA Toolkit。当前最小 demo 不需要 CUDA，只需要显卡驱动正常。

## 3. 安装基础工具

```bash
sudo apt update
sudo apt install -y git curl wget vim build-essential python3-pip python3-venv
```

## 4. 安装 ROS 2 Jazzy

按照 ROS 2 Jazzy 官方文档安装 Ubuntu deb 包。

常用安装检查命令：

```bash
ls /opt/ros/jazzy/setup.bash
```

安装完成后，把 ROS 环境加入 shell：

```bash
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

安装常用 ROS 构建工具：

```bash
sudo apt install -y python3-colcon-common-extensions python3-rosdep
sudo rosdep init || true
rosdep update
```

## 5. 安装 Gazebo Harmonic

ROS 2 Jazzy 对应 Gazebo Harmonic。按 Gazebo 官方文档安装 ROS-Gazebo 组合包。

安装后检查：

```bash
gz sim --version
```

当前 HazardWalker 最小 demo 还不依赖真实 Gazebo 场景，但主力机应提前装好 Gazebo，方便后续平台组接仿真。

## 6. 检查 HazardWalker 仓库

进入你已经 clone 的仓库：

```bash
cd ~/HazardWalker
git status --short --branch
```

建议先切到当前开发分支：

```bash
git fetch origin
git checkout feature/offline-algorithm-tests
git pull
```

先跑离线测试：

```bash
python3 scripts/run_offline_tests.py
```

如果输出 `10 passed, 0 failed`，说明普通 Python 算法测试正常。

## 7. 构建 ROS 2 工作空间

```bash
./scripts/build.sh
```

如果提示找不到 `colcon`，先安装：

```bash
sudo apt install -y python3-colcon-common-extensions
```

## 8. 运行最小 demo

```bash
./scripts/run_minimal_demo.sh
```

运行结束后检查结果文件：

```bash
ls reports/run_results
python3 scripts/evaluate_result.py reports/run_results/<timestamp>_result.json
```

## 9. 主力机 Codex 新对话建议

在主力机 Codex 新对话里，先让 Codex 阅读：

```text
README.md
docs/项目背景介绍.md
docs/初期项目开发总结.md
docs/最小demo实现.md
docs/主力机环境搭建.md
```

然后再让它检查当前分支、工作区状态和主力机环境。

## 10. 不自动下载的大文件

以下内容不要让脚本自动下载，先人工确认：

- NVIDIA CUDA Toolkit
- Gazebo 大型模型资源
- rosbag、视频、点云数据
- YOLO 权重或训练数据集
- 官方平台 SDK 或仿真包

这些文件下载前应先确认保存位置，避免放进 Git 仓库。
